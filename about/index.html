/* About me */

把複雜的事，整理成一看就懂的設計

我是 Liya，一名 UI/UX 設計師。從建築系的設計思考出發，近年專注在 AI 對話產品與通訊軟體，擅長把繁雜的需求整理成清楚的流程與元件，並和產品、工程夥伴一起快速迭代。工作之外，我經營 IG「人生招財貓」，用插畫把理財知識畫成一看就懂的小故事。

/* 我怎麼走到 UX */

從建築走到使用者體驗

在國立金門大學讀了五年建築，設計課用的正是設計思考：先觀察、再發想、和老師一次次討論迭代。在里埕設計工坊，我到現場測量傳統閩式建築、一筆一筆手繪記錄，學會先看懂人怎麼使用空間，再動手設計。

進入建築師事務所後，我和業主來回確認圖說，發現好的設計需要把想法講清楚、讓不同背景的人都能理解。2022 年我把這套方法帶到數位產品，從 UX 課程助教開始，一路走到獨立負責整個產品的設計。

/* 我怎麼工作 */

三個工作習慣

01

先拆小步驟驗證

不一次押注整個方案，先做出能測的版本，再依回饋修正。

Subway 點餐 App 兩輪易用性測試，可用性評分 SUS 55 → 75

02

讓設計好交付

設計不只要好看，還要讓工程容易實作、團隊容易延續。

重構 Design Guideline、建立 Figma 元件庫，降低與 RD 的溝通成本

03

跨角色對齊

和 PM、工程一起確認需求與限制，讓設計符合使用者也做得出來。

AI 對話平台橫跨 Desktop、iOS、Android 三端的設計合作

/* 工作之外 */

用插畫，陪人把焦慮變成底氣

我經營 IG 人生招財貓，每週用療癒插畫把小資理財與真實的金錢故事畫成好懂的圖文。把抽象的知識變成具體行動，和我做 UX 時把複雜流程變簡單，是同一件事。

/* 也喜歡 */

聲音、旅行與陶土

過去和朋友經營 Podcast @地下事，聊建築界生態與日常觀察。休息時喜歡和家人朋友旅行、畫畫、看展和爬山，最近在學陶藝。
